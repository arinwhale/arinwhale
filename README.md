# Mia’s iPhone — A Family Business

A fictional interactive phone featuring an English Kardashian–Jenner family WhatsApp story about nepotism.

Open WhatsApp to read the complete family group chat and six invented private chats. Explore Instagram Stories, Photos, Notes, Calendar and Mail for story extras.

All messages, posts, emails and events are invented fan-made satire. Mia is a fictional younger relative of Kris, not her daughter. Not affiliated with Apple, WhatsApp, Instagram or the Kardashian–Jenner family.

Messages, likes and settings remain in the visitor’s browser. No real messages or calls are sent.

This is a buildless static website. GitHub Pages can publish the main branch from the repository root. Image sources are listed in CREDITS.txt.
